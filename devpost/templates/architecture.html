Architecture

One scan, five stages, streamed live

A Node pipeline screens each fork. A Next.js dashboard shows every stage the moment it lands in Postgres.

01

Discover

GitHub API

Lists every fork of the cookbook. Skips forks whose commit hasn't changed and anyone who opted out.

02

Triage

Claude Sonnet

Diffs the fork against upstream to find the candidate's project, then returns type, stack, Solari products, install and run commands, and a demo goal.

03

Build

Solari Sandbox

Installs and boots in a fresh microVM (a desktop VM for GUI apps) with in-guest timeouts, then exposes the port on a preview URL. Docker fallback without a key.

04

Demo

Solari Browser · Desktop

A Claude computer-use agent explores the app while the session records. Every action becomes a captioned timeline step with Claude's reasoning.

05

Score

Claude Sonnet

Grades boots, works, uses Solari, use case and polish from 1 to 5 using the code, the logs and the demo, and writes a two-paragraph summary.

Submissions are untrusted code

  • Only SUBMISSION_* secrets reach a submission
  • Screener keys redacted before anything is stored
  • Triage reads stay inside the checkout, no symlink escapes
  • Repo text goes to Claude tagged as untrusted data
  • Demo browser can't reach private or loopback hosts
  • Opt-outs checked before and during every run
